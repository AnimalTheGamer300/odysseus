## Layout

- `js/<module>.md` — per JS module: every def with its call sites
- `http-endpoints.md` — every FastAPI route + which JS files fetch it
- `module-deps-python.md` / `module-deps-js.md` — import edges AND reverse dependents
- `dead-code.md` — defs with zero static callers (verify before deleting!)
- `external-calls.md` — most-called names that are stdlib/third-party/dynamic
